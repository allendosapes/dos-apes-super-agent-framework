# Security Policy

## Reporting a Vulnerability

If you discover a security issue in Dos Apes Super Agent Framework, please **do not** file a public GitHub Issue. Instead, email allen@dosapes.com with:

- A description of the issue
- Steps to reproduce
- The version affected (`npm ls dos-apes-super-agent`)

I'll respond within 7 days.

## Supported Versions

Only the version currently published as `latest` on npm receives security updates. The current `latest` is **3.0.0**.

Beta versions (currently 3.4.0) receive security fixes only when they are promoted to `latest`.
